# Elyndor Source of Truth

Repository-level documentation is grouped by ownership:

- `architecture/` — stack, roadmap, product boundaries, phase execution documents, and compatibility rules.
- `gameplay/` — authoritative game-system specifications 01–31.
- `ui/` — UI/UX specifications and mappings to the current boards in `reference/`.
- `../archive/` — historical audits and manifests; never use them as current verification evidence.

Start with the repository `README.md`, then `AGENTS.md`, then read only the smallest relevant Source of Truth set. The full index is `docs/source-of-truth/00_MASTER_PROJECT_INDEX.md`.
