# Лучник — Archer Talent Tree V2

> **AUTHORITATIVE / ACTIVE SOURCE OF TRUTH**  
> Этот документ описывает текущий `ARCHER_TREE` из `content/talents/archer.json`. Старый Arcane Archer / «Тайный стрелок» больше не является активной специализацией и не должен использоваться как ориентир для реализации.

## Класс

- **Primary attribute:** `AGILITY`
- **Resource:** `FOCUS`
- **Weapons:** `BOW`, `CROSSBOW`
- **Armor:** `LEATHER`
- **Companion:** постоянный физический питомец (`PHYSICAL_PET`)
- **Talent points:** максимум 59
- **Tree version:** 2
- **Active branches:** `MARKSMAN`, `BEAST_MASTERY`, `SURVIVAL`
- **Not active:** `ARCANE_ARCHER`, `SPIRIT_PET`, Mana conversion, Intellect/SpellPower/MagicPenetration Archer builds

## Базовый kit с 1 уровня

### Быстрый выстрел — `QUICK_SHOT`

Базовый выстрел Лучника: наносит 90% силы атаки физическим уроном. Стоимость: 15 концентрации.

### Команда: Фас — `COMMAND_ATTACK`

Питомец немедленно использует особую атаку. Стоимость: 20 концентрации. Перезарядка: 10 сек.

Автоатака Лучника остаётся частью resource loop: базовый интервал 00:00:02.4000000, коэффициент Attack Power 0.65, при попадании восстанавливает 4 Focus.

## Правила дерева

- Всего узлов: **96** (32 в MARKSMAN, 32 в BEAST_MASTERY, 32 в SURVIVAL).
- Capstone расположен на Tier 9 и требует 40 вложенных очков в своей ветке.
- Все EventTriggered target IDs ниже являются **canonical runtime IDs**. Runtime должен обращаться к ним напрямую, без alias translation layer.
- Старые runtime-алиасы вроде `JOINT_HUNT`, `AIMED_SHOT_AIM`, `COMBAT_RHYTHM` и typo `BEST_MASTER_OWNER_SHOT` запрещены.

# Canonical integrity rules

1. `content/talents/archer.json` определяет актуальные talent IDs, modifier keys и target IDs.
2. Archer runtime использует эти target IDs напрямую. Добавлять новый compatibility alias можно только как временную миграцию с отдельным тестом и планом удаления.
3. Базовые способности класса не должны повторно открываться талантами. `QUICK_SHOT` и `COMMAND_ATTACK` выдаются через `startingAbilityIds`.
4. `B-2-1` — **Улучшенная команда: Фас**: усиливает special attack `COMMAND_ATTACK`, а не открывает способность.
5. В активном Archer V2 нет Mana/Intellect/SpellPower/MagicPenetration resource override и нет `SPIRIT_PET`.

# Identity

- **Меткая стрельба:** точный physical ranged DPS, Hunter's Mark, Aimed Shot, crit и armor penetration.
- **Повелитель зверей:** sustained pet-centric DPS и синергия хозяина с физическим питомцем.
- **Выживание:** poisons, traps, control, defensive cooldowns и tactical procs.
